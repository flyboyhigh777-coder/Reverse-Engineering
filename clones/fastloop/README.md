# FastLoop

Трекер интервального голодания. Самостоятельная разработка: весь код написан
с нуля и собран вручную, без заимствованных материалов.

## Что внутри

- Онбординг-квиз на 31 шаг, экран анализа, персональный план с прогнозом к дате.
- Пейволл с тремя тарифами, обратным отсчётом и отложенным крестиком.
  **Оплата не проводится, платёжные данные не запрашиваются**: кнопка включает
  локальный флаг PRO.
- Таймер голодания: кольцо на 24-часовом циферблате, лента фаз, правка времени
  старта, 14 схем от 12:12 до суток и своё окно, у каждой — своя страница
  с разбором доказательств.
- Шагомер: аппаратный датчик в Android-сборке, акселерометр как запасной
  вариант в браузере, ручной ввод третьим. Источник всегда подписан.
- Вес с графиком, целевой линией и ИМТ; вода; история; серии; статистика.
- PRO: своё окно с шагом в полчаса, расписание схем по дням недели,
  экспорт всех записей в CSV.
- Шесть статей, тёмная и светлая темы, хранение в `localStorage`.

PRO включён по умолчанию — все схемы, история, правка окна и разбор фаз открыты.
Платная граница есть, но не навязана: в профиле переключатель «Выключить PRO»
показывает, что именно она закрывает. Выбор сохраняется между запусками.

## Запуск

```bash
npm ci
npm run dev        # дев-сервер
npm run build      # типы + сборка в dist/ одним файлом
npm run artifact   # сборка + страница для публикации в artifact/
./android/build-apk.sh   # подписанный APK в build/fastloop.apk
```

## Android-сборка без Google SDK

`dl.google.com` недоступен из окружения, где это собиралось, поэтому
`android/build-apk.sh` обходится без Android SDK и Gradle. Тулчейн собирается
из того, что лежит на доступных зеркалах:

| Нужен | Откуда взят |
|---|---|
| `aapt2` | linux-бинарь внутри `org.apktool:apktool-lib` |
| фреймворк ресурсов (`aapt2 -I`) | `prebuilt/android-framework.jar` оттуда же |
| `android.jar` для `javac` | `org.robolectric:android-all` |
| дексер | `com.jakewharton.android.repackaged:dalvik-dx` |
| подпись | `com.android.tools.build:apksig` |

Скрипт скачивает их один раз в `~/.fastloop-android-kit` (переопределяется
`FASTLOOP_ANDROID_KIT`) и дальше работает офлайн. Нужен только JDK.

Две оговорки по тулчейну. `dalvik-dx` принимает class-файлы не новее Java 8,
поэтому `javac` вызывается с `--release 8`. На Maven Central опубликован только
`apksig` 2.3.0 (2017): его v1-подпись зовёт исчезнувший из современных JDK
`sun.security.pkcs.PKCS7#encodeSignedData`, поэтому подпись делается только по
схеме v2 — Android требует «v2 или выше» для targetSdk 30+, а v1 нужен лишь
ниже API 24, тогда как `minSdk` здесь 24.

Пакет `tools.fastloop`, minSdk 24, targetSdk 34. APK подписан отладочным
ключом, который генерируется локально, — для установки нужно разрешить
установку из неизвестных источников.

## Устройство

Зависимости направлены внутрь: UI знает про домен, домен про UI — нет.

```
src/domain/   типы, схемы, фазы, математика таймера, метрики, статьи, квиз
src/state/    хранилище и действия, адаптер localStorage
src/ui/       экраны, онбординг, пейволл, компоненты
```

- `domain/fasting.ts` — длительности, прогресс, форматирование. Дни считаются по
  локальному времени, не через `toISOString()`.
- `domain/metrics.ts` — ИМТ, норма воды, серии, прогноз веса. Прогноз помечен как
  оценка везде, где показывается.
- `domain/phases.ts` — фазы голодания с оговоркой: границы приблизительны,
  источники расходятся.
- `state/storage.ts` — каждое обращение к `localStorage` в try/catch; приложение
  работает, если хранилище недоступно.

## Что откуда берётся: шаги

| Среда | Источник | Что умеет |
|---|---|---|
| Android-сборка | `Sensor.TYPE_STEP_COUNTER` через JS-мост `FastLoopNative` | считает и когда приложение закрыто |
| Браузер на телефоне | `devicemotion`, счёт пиков ускорения | только пока вкладка открыта и экран не погашен |
| Остальное | ручной ввод | — |

Аппаратный счётчик отдаёт шаги с момента загрузки телефона, поэтому за день
считается разница с базовой отметкой, снятой при первом за сутки показании.
Если приложение в этот день ни разу не открывали, шаги до первого открытия в
день не попадут — интерфейс этого не скрывает.

## Ограничения веб-версии

Нет системных уведомлений и виджетов на домашнем экране, скачивание файлов в
артефактах заблокировано (поэтому экспорт — копирование текста). В интерфейсе
это подписано.

## Не медицинский сервис

Приложение ничего не диагностирует и не лечит. При беременности, диабете, приёме
лекарств или расстройствах пищевого поведения решение о голодании принимается
с врачом.

# FastLoop

Трекер интервального голодания. Самостоятельная реализация, построенная по
разбору приложения GoFasting — см. [ANALYSIS.md](ANALYSIS.md).

Не связан с GoFasting и Gulooloo Tech Co., Ltd., не содержит их кода, ресурсов,
названий и товарных знаков. Из разбора взяты только функциональная структура и
схема продуктовой воронки.

## Что внутри

- Онбординг-квиз на 31 шаг, экран анализа, персональный план с прогнозом к дате.
- Пейволл с тремя тарифами, обратным отсчётом и отложенным крестиком —
  воспроизводит воронку оригинала. **Оплата не проводится, платёжные данные
  не запрашиваются**: кнопка включает локальный флаг PRO.
- Таймер голодания: кольцо на 24-часовом циферблате, лента фаз, правка времени
  старта, 7 схем от 12:12 до OMAD 23:1.
- Вес с графиком, целевой линией и ИМТ; вода; шаги; история; серии; статистика.
- Шесть статей, тёмная и светлая темы, хранение в `localStorage`.

PRO включён по умолчанию — все схемы, история, правка окна и разбор фаз открыты.
Платная граница оригинала воспроизведена, но не навязана: в профиле есть
переключатель «Выключить PRO», чтобы посмотреть, что именно оригинал запирает.
Выбор сохраняется между запусками.

## Запуск

```bash
npm ci
npm run dev        # дев-сервер
npm run build      # типы + сборка в dist/ одним файлом
npm run artifact   # сборка + страница для публикации в artifact/
```

## Устройство

Зависимости направлены внутрь: UI знает про домен, домен про UI — нет.

```
src/domain/   типы, схемы, фазы, математика таймера, метрики, статьи, квиз
src/state/    хранилище и действия, адаптер localStorage
src/ui/       экраны, онбординг, пейволл, компоненты
```

- `domain/fasting.ts` — длительности, прогресс, форматирование. Дни считаются по
  локальному времени, не через `toISOString()`.
- `domain/metrics.ts` — ИМТ, норма воды, серии, прогноз веса. Прогноз помечен как
  оценка везде, где показывается.
- `domain/phases.ts` — фазы голодания с оговоркой: границы приблизительны,
  источники расходятся.
- `state/storage.ts` — каждое обращение к `localStorage` в try/catch; приложение
  работает, если хранилище недоступно.

## Ограничения веб-версии

Нет шагомера (шаги вводятся вручную), нет системных уведомлений и нет виджетов
на домашнем экране. В интерфейсе это подписано.

## Не медицинский сервис

Приложение ничего не диагностирует и не лечит. При беременности, диабете, приёме
лекарств или расстройствах пищевого поведения решение о голодании принимается
с врачом.
